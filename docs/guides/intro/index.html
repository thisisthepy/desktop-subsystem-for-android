      Desktop Subsystem for Android™ (DSA)

      Android apps run as real desktop windows.Android 앱이 실제 데스크톱 창으로 실행됩니다.

      Android itself keeps its own kernel and runs whole in a dedicated virtual machine. DSA hands each of its tasks to the host as a native window. Nothing in Android is emulated or translated. The host supplies only what a desktop owns: windows, input and devices.Android는 자체 커널을 그대로 쓰며 전용 가상 머신 안에서 온전한 시스템으로 실행됩니다. DSA는 그 안의 작업을 하나씩 호스트의 네이티브 창으로 띄웁니다. Android의 어느 부분도 에뮬레이션하거나 번역하지 않습니다. 호스트는 창과 입력, 장치처럼 데스크톱이 원래 가진 것만 제공합니다.

      Left: Android, running on its own. Right: your desktop. The windows below are movable, focusable and closable, by pointer or keyboard (arrow keys on a title bar move it, Delete closes it).왼쪽에서는 Android가 따로 실행되고, 오른쪽은 데스크톱입니다. 아래 창은 마우스나 키보드로 옮기고, 앞으로 가져오고, 닫을 수 있습니다. 제목 표시줄을 선택한 뒤 화살표 키로 옮기고 Delete 키로 닫습니다.

      android / own system

      Android runs whole, in its own VM.Android는 전용 VM에서 통째로 실행됩니다.

      Android runs in a dedicated lightweight VM on a kernel that DSA builds and ships, with binder built in. The kernel, ART and the framework are Android's own. No system call is translated, the user's WSL setup is never touched, and no user has to build or replace a kernel.Android는 전용 경량 VM에서 실행되고, 커널은 DSA가 binder를 포함해 직접 빌드하고 함께 배포합니다. 커널, ART, 프레임워크는 손대지 않은 Android 그대로입니다. 시스템 호출을 번역하지 않고, 사용자의 WSL 설정도 건드리지 않습니다. 사용자가 커널을 빌드하거나 교체할 필요도 없습니다.

      As a result, apps run on the Android they were built for, and the host system is left unchanged.그래서 앱은 원래 대상으로 삼은 Android 환경에서 그대로 동작하고, 호스트 시스템은 바뀌지 않습니다.

      android / one task, one window

      One task, one native window.작업 하나에 네이티브 창 하나.

      There is no phone frame showing the whole Android screen. Each Android task gets its own host window, with its own taskbar button, Alt+Tab entry, Start menu entry and notifications. A custom hwcomposer hands each task's layers to the host, and each frame is copied GPU to GPU through a shared texture into the window, never through the CPU.Android 화면 전체를 휴대폰 모양 틀에 담아 보여 주지 않습니다. Android 작업마다 호스트 창이 하나씩 열리고, 작업 표시줄 단추와 Alt+Tab 항목, 시작 메뉴 항목, 알림도 각각 생깁니다. 전용 hwcomposer가 작업별 레이어를 호스트에 넘기고, 프레임은 공유 텍스처를 통해 GPU 안에서 창으로 복사됩니다. CPU는 거치지 않습니다.

      The host is the shell. Android carries no launcher, no status bar and no keyboard app; text input comes from the host's own input method. The windows on this page behave the same way: move one, bring it forward, close it.셸 역할은 호스트가 맡습니다. Android 안에는 런처, 상태 표시줄, 키보드 앱이 없고, 글자 입력은 호스트의 입력기가 처리합니다. 이 페이지의 창도 같은 방식으로 다룰 수 있습니다. 옮기고, 앞으로 가져오고, 닫아 보십시오.

      android / the HAL boundary

      Devices cross at the HAL, nowhere else.장치는 HAL에서만 경계를 넘습니다.

      The dashed line beside this page is the hardware abstraction layer. Everything above it stays in Android. The host lends its devices across it as HAL services over RPC Binder, so Android talks to a camera or a speaker the way it always does, and the host decides what is lent. Every app's OpenGL ES runs on ANGLE over Vulkan, and the Vulkan calls are carried to the host GPU.페이지 옆의 점선이 하드웨어 추상화 계층(HAL)입니다. 그 위쪽은 모두 Android 안에 있습니다. 호스트는 장치를 RPC Binder 기반 HAL 서비스로 이 경계 너머에 빌려줍니다. Android는 카메라나 스피커를 평소와 똑같이 쓰고, 어떤 장치를 빌려줄지는 호스트가 정합니다. 모든 앱의 OpenGL ES는 Vulkan 위의 ANGLE로 실행되고, Vulkan 호출은 호스트 GPU로 전달됩니다.

      Control messages have one definition, and the codecs for Rust, Java and C++ are generated from it. Every connection checks the protocol version, the schema hash and a per-boot secret. Lend a device:제어 메시지는 정의 하나에서 Rust, Java, C++ 코덱을 모두 생성합니다. 연결할 때마다 프로토콜 버전과 스키마 해시, 부팅할 때마다 새로 만드는 비밀 값을 확인합니다. 아래에서 장치를 빌려줘 보십시오.

      android / idle and memory

      No window open means Doze, and memory goes back.창을 모두 닫으면 Doze, 메모리는 호스트로 돌아갑니다.

      When no Android window is shown, Android enters Doze, as a phone does in a pocket: notifications still arrive and the CPU rests. Memory that Android frees is reported and returned to the host while it runs, not only when it stops. Freezing the guest is opt-in, never the default.화면에 Android 창이 하나도 없으면 Android는 주머니 속 휴대폰처럼 Doze 상태가 됩니다. 알림은 계속 받고 CPU는 쉽니다. Android가 쓰지 않게 된 메모리는 종료할 때만이 아니라 실행 중에도 계속 호스트에 반환됩니다. 게스트 동결은 사용자가 켤 때만 동작하며 기본값이 아닙니다.

      Close the windows on this page and watch the rail: tasks leave, the memory figure falls, and Android dozes.이 페이지의 창을 닫으면서 왼쪽을 보십시오. 작업 목록이 줄고 메모리 수치가 내려가며, 창을 모두 닫으면 Android가 Doze 상태로 바뀝니다.

      android / three hosts

      One guest, three hosts.게스트 하나, 호스트 셋.

      The protocol, the guest and the host core name no operating system. Each host adds only its VM, its transport and its window system, so the Android that runs is the same on all three.프로토콜, 게스트, 호스트 코어는 특정 운영체제에 의존하지 않습니다. 호스트별로 VM, 전송 계층, 창 시스템만 따로 구현하므로 세 호스트 모두에서 같은 Android가 실행됩니다.

      android / open source

      Built from parts anyone may carry on.누구나 이어받을 수 있는 코드로 만듭니다.

      Microsoft ended the Windows Subsystem for Android on March 5, 2025, and the apps people ran with it lost their place on the desktop. DSA covers what it did and goes further, on Apache-2.0 code with no proprietary binaries. No app store and no Google Play services ship with DSA; installing them stays the user's choice.Microsoft는 2025년 3월 5일 Windows Subsystem for Android 지원을 종료했고, 그 위에서 쓰던 앱은 데스크톱에서 실행할 방법을 잃었습니다. DSA는 그 기능을 모두 제공하고 그 이상을 목표로 하며, 독점 바이너리 없이 Apache-2.0 코드로 만듭니다. 앱 스토어와 Google Play 서비스는 포함하지 않으며, 설치 여부는 사용자가 정합니다.

      Development is public: issues, pull requests, and a test for every specified behaviour.개발은 모두 공개되어 있습니다. 이슈와 풀 리퀘스트를 누구나 볼 수 있고, 명세한 동작마다 테스트가 있습니다.
