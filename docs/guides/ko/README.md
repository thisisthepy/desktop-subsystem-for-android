# DSA 사용 안내서

Desktop Subsystem for Android™(DSA)를 설치하고 쓰는 방법, 문제가 생겼을 때 할 일을 안내합니다.

[English](../README.md) · **한국어**

이 안내서는 현재 개발 중인 버전을 기준으로 합니다. 최신 릴리스에는 여기 설명한 기능 중 일부가 아직 없을 수
있으며, 릴리스에 무엇이 들어 있는지는 릴리스 노트에서 확인할 수 있습니다. 아직 완성되지 않은 기능은 그렇다고
적어 두었습니다.

| 안내서 | 할 수 있는 일 |
|---|---|
| [시작하기](getting-started.md) | Windows에 DSA를 설치하고, Linux와 macOS 지원 현황을 확인합니다 |
| [앱과 창](apps.md) | 앱을 열고 창, 알림, 위젯, 백그라운드 앱을 다룹니다 |
| [APK 설치](install-apks.md) | APK 파일로 앱을 설치하고, 설치가 거부된 이유를 확인합니다 |
| [파일](files.md) | 파일 탐색기에서 Android 파일을 열고, Android 앱으로 파일을 보냅니다 |
| [Android 버전](android-versions.md) | 실행 중인 Android 버전을 확인하고 바꿉니다 |
| [설정](settings.md) | DSA 설정의 각 항목과 해당 `dsa settings` 이름을 찾습니다 |
| [메모리](memory.md) | Doze, 일시 정지, 메모리가 PC로 돌아가는 방식을 이해합니다 |
| [개발자 모드와 adb](developer-mode.md) | adb를 Android에 연결합니다 |
| [문제 해결과 로그](troubleshooting.md) | 문제를 진단하고, Android 로그를 보고, 문제를 보고합니다 |
| [제거](uninstall.md) | DSA를 제거하고, 무엇이 남는지 확인합니다 |

프로젝트를 처음 접한다면 [소개 페이지](../intro/index.html#ko)부터 보십시오.
