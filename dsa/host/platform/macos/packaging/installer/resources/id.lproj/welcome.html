Desktop Subsystem for Android™

DSA menjalankan aplikasi Android di Mac Anda, masing-masing di jendelanya sendiri.

Klik Lanjutkan untuk menginstal DSA.

Desktop Subsystem for Android adalah proyek sumber terbuka yang independen. DSA tidak berafiliasi dengan, tidak didukung oleh, dan tidak disponsori oleh Microsoft maupun Google. Android adalah merek dagang Google LLC.
